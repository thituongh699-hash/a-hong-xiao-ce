# 参数优化模块

模块已经在 `src/optimization/` 实现，当前首个适配器是“拐弯买入点”。搜索引擎独立于策略，项目内其他策略可提供同样的评估函数接入；网页入口目前只启用已检查成交时点的适配器。

## 搜索与验证

- 参数空间支持字段网格或明确的配置列表，最多 100000 组；可用固定随机种子抽样，并限制实际计算次数。
- 每组参数返回指标字典，由调用者指定排名指标、参数限制、最少样本条件。异常和非有限得分不参与排名。
- 每次试验追加保存记录。断点恢复必须同时匹配行情、信号、参数、成本、代码版本、评估/筛选/约束回调版本、时间分段指纹，防止混用过期结果。
- 本策略先运行训练期，保存 `frozen-best-training.json`，再验证冻结的参数。验证期结果不重新选择参数。按训练排名展示前十名，及每种买入方式在训练期选出的退出条件。
- 不自动写入策略配置或实盘参数；研究结果和当前项目配置分别保存。

此设计参考了 [backtesting.py 的优化接口源码](https://github.com/kernc/backtesting.py/blob/master/backtesting/backtesting.py)中的参数网格、条件限制和搜索次数控制，以及 [Backtrader 的成交撮合源码](https://github.com/mementum/backtrader/blob/master/backtrader/brokers/bbroker.py)中的开盘跳空与触发价处理。本项目使用自己的成交服务，未安装或替换为这些框架。

## 当前策略参数

箭头条件保持严格的最高涨幅大于 7.2%、收盘涨幅大于 1% 且小于 4.8%，并沿用前轮“初拐”形态定义。形态判定是对截图的可解释近似，尚不是用户提供的完整形态公式。

默认搜索 650 组：盘中突破 3% / 4% / 4.5% / 5%、收盘确认后次日开盘；固定止盈、滑动退出、盈利后固定回撤、MA10 次日退出；止损 4% / 6% / 8% / 10%，固定止盈 8% / 12% / 15% / 20%，滑动激活 5% / 10% / 15%，收紧回撤 3% / 5%，固定回撤 5% / 8%，最长持有 20 / 40 个交易日。

“4日内”使用信号后的四个市场交易日，不含信号日；停牌不延长窗口。百分比基准为触发日上一交易日收盘，比较符号为严格大于。盘中达到阈值的第一个有效分价模拟买入，跳空高开按开盘价；另加 0.1% 买入滑点。收盘涨停拒绝收盘买入；涨停开盘拒绝盘中与开盘买入。日K不能验证排队、盘口流动性与所有日内路径。当天收盘确认后按当天收盘成交只作理论对照。

初期优化按独立信号实验进行，不是资金共享的组合回测。同一股票或持仓日期可以重复。分数默认是每信号均值减去 0.25 倍亏损收益的均方根，未买入信号计为零；至少 30 次成交且成交比例达到 20% 才能排名。未平仓按区间末收盘估值并扣估计卖出费，不视作已成交。原价价格带异常在预先固定的共用窗口内筛查（4日观察期 + 执行缓冲 + 配置中的最长持有期），观察窗口不足的信号也从该区间所有参数组一致剔除。价格异常筛查仍使用信号之后的行情，存在事后选择偏差，不能替代逐日公司行动数据。延迟退出遇到窗口外不可信价格时停止结论。

同时比较次日开盘模式时，共同比较样本还要求观察日四之后存在一个执行缓冲日，使各方式的观察条件完整一致。行情从2025年起读取，60根此前行情要求不含信号当天；本地交易日历采用所有候选股票行情日期的并集，尚未经交易所日历核验；完整日期序列计入恢复指纹。

## 项目接入

通用搜索的评估函数只负责训练段：

```python
from src.optimization import ParameterOptimizer

def evaluate(parameters):
    # 使用项目的策略回放，返回数值指标；此处只读取训练段。
    return run_strategy_on_training_data(parameters)

result = ParameterOptimizer().run(
    {"lookback": [10, 20, 40], "stop_pct": [4, 6, 8]},
    evaluate,
    objective="score",
    max_trials=100,
    seed=42,
    checkpoint="reports/experiment/checkpoint.jsonl",
    context={"adapter": "my-strategy-v1", "data_hash": "...", "training_period": ["...", "..."]},
    evaluator_version="my-strategy-v1",
    eligibility_version="min-trades-30-v1",
    eligible=lambda metrics: metrics["trades"] >= 30,
)
# 保存 result.best 后，再单独运行验证段。
```

运行本轮适配器：`scripts/optimize_turning_points.py`，可用 `--config` 指定参数 JSON、`--out` 指定研究结果目录。网页入口 `/optimization`，后台任务接口 `/api/optimization/jobs`。任务采用独立进程，一次运行一个，保留进度日志和结果；失败不会显示成已完成。支持取消和在原目录、原任务编号上恢复；任务状态原子持久化，跨进程文件锁防止并发重复启动。取消在当前试验结束后的进度回调生效；不能确认工作进程已退出时继续阻止重复任务。

后续策略接入时需检查信号与成交时点、涨跌停价来源、T+1 和手续费，且提供策略代码与数据指纹。主 `BacktestEngine` 已将完整K线生成的信号推迟到下一根K线开盘撮合；最后一根K线产生的信号不成交。当前通过专用回放调用项目 `TdxProvider`、`OrderMatcher`、`ExecutionEngine`、`AccountLedger`，尚未与主引擎的共享资金组合回放统一，其他策略仍需要各自接入和验收。

## 研究验收

训练参数先冻结，再检查训练与验证得分是否高于每信号0%的现金基准，以及验证成交样本是否达到预设下限。负收益或验证样本不足标为“当前假设未获支持”；全部通过也仅表示可进入下一轮研究。报表提供股票/信号周集中度、训练参数单轴敏感性，不根据验证结果改选参数。默认关闭当天收盘成交；主动开启时明确标为理论对照。

## 数据边界

本地行情截至 2026-09-29。股票名称快照为 2026-08-05，剔除了其中 ST、*ST、退市名称；没有逐日风险警示状态历史，不能确认整个回测期所有时点都非ST。使用主板普通 10% 价格带从前收盘原价推算，要求至少60根此前行情以避开上市初期，但仍缺独立除权参考价、上市状态和复权因子，未计分红送转。沪深交易规则发生调整时，应使用逐日证券状态而不能把当前规则无条件套到历史。

成本为佣金万2.5、最低5元，卖出印花税0.05%，双边滑点0.1%，过户费沿用项目0设置。印花税减半的来源为 [财政部、税务总局2023年第39号公告](https://szs.mof.gov.cn/zhengcefabu/202308/t20230827_3904226.htm)。当前结果用于检验参数敏感性，不能据此确认实盘收益。
