# 回测交易范围

回测控制栏新增“交易范围”勾选面板。上市板块与股票类型分别选择，两个分组各至少选一项；标的必须同时满足两个分组。

| 分组 | 可勾选项 | 首次打开的默认值 |
| --- | --- | --- |
| 上市板块 | 沪深主板、创业板、科创板、北交所 | 全部四个板块 |
| 股票类型 | 普通股、ST / *ST、退市整理 | 仅普通股 |

面板提供“全选板块”和“仅主板”。勾选偏好保存在当前浏览器；每次提交冻结当时的选择，运行期间调整勾选不会改变已提交任务。范围用于筛选输入的标的，不会自动创建全市场回测。

## 接入范围与校验顺序

- 股票搜索：带范围时先筛选，再截取最多十条搜索结果。
- 单票回测：前端先预览范围，再检查行情口径，再提交；后端在取消旧任务或写报告前再次校验。
- 智能选股和AI筛选的批量回测：先筛选范围，再应用Top N和生成任务，提示被排除的标的。
- 通用CSV批量回测：范围随子进程参数传递；串行与并行worker在修改数据源或启动单项回测前预览并核验范围。范围外任务记录失败原因；网络或预览异常时不启动。
- HTTP、WebSocket、内部回测任务和主回测引擎均支持显式范围。主引擎在初始化行情服务前校验，最终报告保存范围及分类依据。

旧客户端省略`trading_scope`时保持原有行为。显式传入时必须完整、合法，空分组、未知枚举、遗漏字段均拒绝，不能自动扩大范围。

## API

`GET /api/backtest/trading_scope/options`返回选项与默认值。

`POST /api/backtest/trading_scope/preview`接收：

```json
{
  "stock_codes": ["600036.SH", "300750.SZ", "920001.BJ"],
  "trading_scope": {
    "boards": ["main_board", "beijing"],
    "stock_types": ["normal"]
  }
}
```

返回`eligible_codes`、带原因的`excluded`和`metadata`。相同`trading_scope`对象可用于`/api/control/start_backtest`、`/api/screener/batch_backtest/start`和`/api/batch/run/start`。命令行批量工具使用`--trading-scope-json`传入同一JSON对象；JSON是一个独立命令行参数。

## 分类与限制

板块按证券代码和交易所后缀保守识别。支持北交所920代码及明确标注`.BJ`的旧代码；未带交易所的43/83/87旧号存在新三板歧义，不能仅凭号段视为北交所。ETF、指数、B股、港股和不能确认板块的代码不会混入显式A股范围。

CSV批量导入复用统一代码规范化，920裸代码不再误归深市。股票名单刷新保留920号段和数据源提供的交易所后缀；本次未联网刷新或改写现有名单。使用北交所回测仍需要名单含对应名称、数据源提供对应行情。

ST与退市分类依据现有股票名单名称。缺少名称且限定股票类型时拒绝；三个股票类型全部勾选时可接受名称未知的板块内标的，并在元数据中列出未核验代码。名称分类不会证明回测期间逐日历史ST或退市整理状态；退市标的也可能不在当前名单中。报告始终标注`historical_st_status_verified=false`。这仍是当前名单筛选，历史时点股票池需要证券主数据升级。

选择板块不会自动补齐该板块的行情，也不会自动改善涨跌停、停牌或退市撮合规则。当前回测引擎原有规则与数据源能力仍须分别验收。

号段依据核对了[北交所920号段公告](https://www.bse.cn/important_news/200021617.html)与[深交所证券代码区间表](https://www.szse.cn/marketServices/technicalservice/doc/P020240510623040090566.pdf)，分类测试覆盖误分类边界；公告信息不能替代本项目的历史证券主数据。

## 验证

离线测试覆盖板块/名称分类、输入校验、范围外请求保留旧任务、搜索截断顺序、批量Top N顺序、子进程参数、WebSocket和主引擎报告。前端契约测试验证勾选序列化、持久化、空选择拦截及任务传递。

浏览器脚本使用真实dashboard与HTTP范围接口，配合合成股票名单、固定行情验收结果和任务启动桩；不启动生产生命周期或修改用户配置。其截图与JSON保存在`reports/upgrades/2026-10-08/trading-scope/`。主引擎另用内存行情完整执行验证，浏览器验收不代表外部行情源或真实交易能力通过。
