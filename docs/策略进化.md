# 策略进化

`src/evolution/` 是一个增量层：不改回测引擎、不改策略基类，用事件总线把「生成 → 审核 → 回测 → 评分 → 入库」串成闭环，跑在后台线程里持续迭代。

## 组成

| 组件 | 职责 | 发布事件 |
|---|---|---|
| `Orchestrator` | 装配 Agent 与订阅关系，触发起点 | `Start` |
| `Researcher` | 基于历史策略生成候选 | `StrategyGenerated` |
| `Critic` | 硬规则审查（合规、可编译、参数范围） | `StrategyApproved` / `StrategyRejected` |
| `Trader` | 调回测适配器执行 | `BacktestFinished` |
| `MemoryAgent` | 统一评分、写入记忆 | `StrategyScored` |
| `LibraryCommitter` | 达阈值后入库 | `StrategyCommitted` |
| `EvolutionRuntimeManager` | 后台线程循环 `run_once`，维护运行态并推送 | — |

Agent 之间不直接调用，只通过 `EventBus.publish / subscribe` 通信，加 Agent 不影响既有链路。

## 选种与入库规则

- **选种**：默认从全量策略库（内置 + 自定义）取，可用 `seed_strategy_id` / `seed_strategy_ids` 限定；`include_builtin=false` 可只从自定义策略选。
- **版本**：入库采用**追加**模式，不覆盖父策略；同一父策略的版本号递增（`v1`、`v2`…）。
- **中间态不落库**：候选策略只在事件流里参与审核与回测，只有达到分数阈值才写入策略库。
- **评分**：多标的 × 多周期分别回测后聚合指标再打分，避免只在一只票、一个周期上过拟合。

## 配置

写在 `config.json` 的 `evolution` 段：

| 键 | 默认 | 说明 |
|---|---|---|
| `seed.strategy_id` | 空 | 指定单个起点策略 |
| `seed.strategy_ids` | `[]` | 允许进化的策略 ID 集合 |
| `seed.include_builtin` | `true` | 是否允许内置策略参与选种 |
| `seed.only_enabled` | `true` | 只从已启用策略选种 |
| `evaluation.stock_codes` | `[]` | 评估标的池，空则回退全局 `targets` |
| `evaluation.timeframes` | `["1min"]` | 评估周期集合 |
| `persist.enabled` | `true` | 是否启用入库 |
| `persist.score_threshold` | `0.2` | 入库分数阈值 |

## 启动

```http
POST /api/evolution/start
Content-Type: application/json

{
  "interval_seconds": 1,
  "max_iterations": 20,
  "seed_strategy_id": "09",
  "seed_strategy_ids": ["09", "34A", "58"],
  "seed_include_builtin": true,
  "seed_only_enabled": true,
  "target_stock_codes": ["000001.SZ", "600519.SH"],
  "timeframes": ["1min", "5min", "15min"],
  "persist_enabled": true,
  "persist_score_threshold": 0.25
}
```

请求体里的字段优先级高于 `config.json`，只对本次运行生效。

## 观测

- 状态查询：`GET /api/evolution/status` 拉当前轮次、候选、评分与 Top 榜。
- 实时推送：WebSocket 订阅 `evolution_state` 与 `evolution_tick`，看板据此刷新。
- 历史：`docs/evolution_gene_runs.sql` 是基因运行记录的建表语句。

## 代码位置

```text
src/evolution/
├─core/        # EventBus、Orchestrator、RuntimeManager、基因编码
├─agents/      # researcher / critic / trader / analysis / library_committer
├─adapters/    # 回测、策略库、LLM、筛选器的对接层
├─algorithms/  # 遗传算法
├─memory/      # 评分与分析结果持久化
└─dashboard/   # 监控页（历史实现，主入口已收敛到 server.py）
```
