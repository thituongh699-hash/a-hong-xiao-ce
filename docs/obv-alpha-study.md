# OBV 日周共振价值检验

入口：`scripts/research_obv_resonance.py`。图表：`scripts/plot_obv_study.py`。
只做研究输出，不更改项目交易配置或自动买卖。

固定原始因子：MAOBV18，包含本周，截至每个交易日收盘重算临时周线；
周OBV连续两次严格上涨、周OBV高于周MAOBV、日OBV高于日MAOBV。
没有选参或收益最高参数搜索。

## 预先锁定的检验

- 研究区间2023-10-01至本地行情末日，当前为2026-09-30，使用2022年起数据预热。
- 当前名单中的沪深主板正常股票；每个信号日至少120根历史日K和完整18根周K。
- 主要期限10日；1/5/20日、单独日条件、单独周条件、首次触发为探索性补充。
- 前两年为历史描述，2025-10-01开始的最近一年单独检验；所有标签和交易退出
  必须落在其报告区间内，跨年/跨发现期边界的结果不能导入前一区间。
- 每个日期在同一合格股票池中比较因子为1和0；动量20五分位×波动率20三分位匹配，
  单个匹配格至少各3只股票，并报告选中股票覆盖率。
- 逐日横截面回归同时控制10/20/60日动量、20日波动率、20日平均成交金额对数；
  连续控制变量在当日截面1%/99%截尾并标准化。
- 推断按日期聚合，以HAC滞后h+1和40个市场日整日期分块bootstrap（2000次、固定种子）
  处理共振持续、收益重叠及共同市场冲击，不对单个股票日进行独立样本推断。

主要价格标签为**信号日收盘至h个市场日之后收盘**的复权价格收益。
其中涉及后续价格的列只作为评价标签，不可用于信号计算。
没有真实交易时点的标签不能等同于现金交易收益。

## 执行实验

复用项目OrderMatcher、ExecutionEngine和AccountLedger。
每个0→1事件是一次独立10万元现金实验，信号收盘后仅在下一市场日开盘尝试买入；
停牌或缺失该日股票K线不延后等买，不沿用此前研究的“4日内涨幅>3%”入场。

固定5/10/20日退出中的h指**买入之后h个市场交易日的收盘**，
例如信号t、买入t+1、h=10退出t+11。另比较共振失效后下一日开盘退出，
最长20日，以及双边滑点从0.1%提高到0.3%的压力测试。

100股整数手、费用内买入预算、T+1，开盘涨停不能买、跌停不能卖，
失败卖出最多尝试后5个市场日开盘。开盘决策不用当天后来发生的高低价。
现金结算使用原价；持仓跨公司行动、无法验证原价参考或期末未能退出时，
保留入场及原因，将普通收益结论标为缺失。

基准沪深300用同一入场/实际退出时点的指数价格收益；独立试验允许区间重叠，
这些交易均值不是一个共享账户的收益，也不能累加为组合年化或用笔数作独立样本数。

## 运行与审计

```powershell
python scripts/research_obv_resonance.py
python scripts/verify_obv_study_outputs.py reports/obv-alpha-2026-10-10
python scripts/plot_obv_study.py reports/obv-alpha-2026-10-10
python scripts/render_obv_study_report.py reports/obv-alpha-2026-10-10
python -m pytest tests/unit/test_obv_research.py tests/unit/test_obv_alpha_statistics.py tests/unit/test_obv_execution_replay.py tests/unit/test_obv_resonance_factor.py tests/unit/test_price_adjustment.py -q
```

只读本地TDX文件和已抓取的BaoStock复权缓存，不联网刷新输入。
报告目录先写预声明设计，再计算；输入、代码和序列化数据都有SHA256。
复用缓存时验证完整指纹，不能通过延长缓存TTL绕开变化检测。

输出在`reports/obv-alpha-2026-10-10/`：HTML/Markdown报告、图表、全部
统计CSV、日期效应CSV、信号标签及逐笔交易CSV.gz、数据覆盖、输入指纹和运行摘要。
用`--max-stocks`和独立`--out`做小样本流程核验时，结果只能称作小样本。
图表和HTML排版只读取已经导出的数值，不重新计算或筛选最优参数。

本轮数值运行的15个源码文件保存在报告目录`executed-source/`，逐一记录SHA256。
数值运行结束后补强了数据生成器来源绑定，将股票池筛选helper、配置解析和TDX指标helper
纳入后续缓存校验；这仅改变缓存契约，没有改变本轮因子或回放计算。
因此本轮旧`dataset.pkl`在当前代码下直接`--reuse`会按设计拒绝；导出的数值与归档源码仍可核验。
需要重新运行时使用新的`--out`目录并重新加载输入。输出核验使用本轮归档源码，
同时在`verification.json`单独列出工作区当前源码与归档的差异。

## 结论边界

当前名单时间2026-08-05，缺历史ST及退市样本；行业和市值未纳入控制。
因而本轮只能评价当前幸存股票样本中的增量预测信息，不能证明完整风险模型alpha。
日K没有盘口排队/真实冲击成本，公司行动现金与股数核算未实现。
最近一年主要匹配超额和条件系数均须在两种95%区间下高于0，并且原价交易
扣费后为正，才记录为本轮通过；即使通过，也仍需真实历史股票池和组合验证。
