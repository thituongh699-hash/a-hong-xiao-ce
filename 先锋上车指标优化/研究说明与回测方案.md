# 先锋·上车指标优化研究包

2026-10-17。仅用于技术指标和量化研究，不构成收益保证或交易建议。

本地历史研究已继续完成，结果与覆盖限制见[研究结果.md](研究结果.md)。新增`运行历史事件研究.py`、`生成研究报告.py`、`核对历史研究结果.py`，原始输出在`历史研究结果_20261017/`。研究使用2020年以来已有行情、历史上市退市信息和官方复权缓存；退市覆盖不完整，仍不能认定是无幸存者偏差的全A股回测。

本轮还修正Python中V2趋势条件为严格`C>MA15`，加入统一预热且保留预热期FILTER冷却状态。下文保留最初方案与CSV研究脚本的使用说明；当前本地历史研究的实际口径以新增报告为准。

## 包含文件

- `先锋上车V2_量价共振副图.txt`：同花顺副图公式，建议放在日线。
- `先锋上车V3_双信号副图.txt`：同花顺副图，区分放量突破与非突破量价共振，增加单独的转弱警示。
- `先锋上车V2_条件选股.txt`：同一V2规则的条件选股版。
- `先锋上车事件研究.py`：对原版和分步优化版实施固定持有期事件研究。需要 pandas、numpy。

代码结构已通过Python语法检查，并用**合成数据**进行功能运行测试。这不是历史A股回测，不能据此宣称预测效果。

## 确切修改

1. 保留原先锋线形式 `4*K10-3*D10`，将二次SMA的`3.2`改为标准整数`3`，有轻微数值差异，不代表原始公式必然无法使用。
2. 原30期曲线 `3*D30` 改为 `D30`，恢复与先锋基准可比的尺度（先锋仍有放大过冲，可能超出0—100）。
3. 将六参数 `STICKLINE(...,2,0,0)` 改为常见的五参数 `STICKLINE(...,2,0)`。
4. 在连续无波动条件下，以分母下限0.01避免除零；这项保护会改变极端静止区间的取值。
5. 放量条件由超过前9日最大成交量，扩展为同时超过前10日平均成交量的1.30倍；1.30只是候选，不是经过回测选出的优值。
6. 要求今日收阳、相对于昨收上涨、收盘在日内高低区间上方35%以内（收盘位置系数≥0.65）。
7. 要求收盘高于15日均线且该均线较3日前上升。
8. 要求先锋>25且走高、中期曲线不下降。
9. 简化原有五组涨幅上限，只保留3日<17%、10日<50%。
10. 将`FILTER(...,9)`统一应用于原始总信号后，分别标注V3是否突破前20日最高价。
11. 单独的“转弱”仅为价格/动量预警，不是测试过的止损或卖出信号。

## 如何在同花顺试用

1. 打开同花顺PC端公式管理，创建**技术指标→副图**，粘贴V2或V3整个公式。
2. 创建**条件选股**公式时单独粘贴选股版；它应只有一个输出 `XG:`。
3. 建议先选用日线；换为30分钟线等后，10、15、30都变为该图表的周期数，不再表示天数。
4. 不同客户端版本对中文变量、颜色和指标样式可能有差异，以客户端公式检验结果为准。若版本不支持注释，可删除花括号中的注释。工具作者不能远程验证用户本地编辑器。
5. 指标盘中会变化，只有在当根日K收盘后才可把信号当作已确认。

## 离线事件研究使用说明

安装：`pip install pandas numpy`

行情CSV首行必须是：`date,symbol,open,high,low,close,volume`。

例如：

```
date,symbol,open,high,low,close,volume
2023-01-03,600000.SH,7.11,7.24,7.04,7.20,951200
```

以上数值仅用于说明格式，不代表该股票真实行情。每只股票至少建议提供100个交易日以上数据；正式回测应尽可能覆盖多个行情阶段。

运行：

```
python 先锋上车事件研究.py --input prices.csv --outdir results --cost-bps 30
```

输出：`signals.csv`（信号表），`events.csv`（逐个事件的固定持有期收益），`summary.csv`（各策略1、5、10、20个交易日的平均收益、中位数、正收益比例及笔数）。

- 信号只使用T日及以前数据。
- 按T+1日开盘价假定进入，按T+1+H日开盘价假定退出。
- 30bp只是示例的往返总费用假设，不是中国股市当期统一费率，应按时间、标的、佣金、税费和冲击成本具体计算。
- 这是事件研究而非可执行资金组合回测，**尚未处理封涨停/停牌不可买入、涨跌停不能卖出、T+1、资金重叠、信号拥挤或行业超额收益**。
- pandas 的SMA复现使用指数递推，和同花顺初始值可能不同；信号比对时要设置预热期。
- CSV中价格的除权口径应前后一致；成交量需检查拆细、送股等股本事件的量纲一致性。

## 从事件研究到可靠回测的工作流程

1. 全量历史股票池：包含已退市的股票，筛选历史某日当时可交易的证券，去除未来成分股名单的生存偏差。
2. 对照：原版、仅增加量比、再增加K线质量、再增加趋势、最终V2，以及V3突破和非突破两组。
3. 多个市场状态、行业与市值分组：至少将上涨、震荡、下跌分开；配对同日同业类似市值和近20日涨幅的未触发股票。
4. 事件期收益：T+1开盘入场，计算后续1、5、10、20日的净收益与同业/宽基超额收益；对同股、同日相关性进行聚类稳健或区块自助法估计。
5. 研究区间建议训练2016—2021，验证2022—2024，测试2025—2026（实际数据可获得截止日期之前）；不要在测试集上再次选参数。
6. 敏感性网格：成交量倍数1.1/1.3/1.5，收盘位置0.55/0.65/0.75，均线10/15/20，先锋阈值15/25/35，冷却期5/9/14；避免全排列盲搜，采用单变量/少量交互、预先规定的比较。
7. 需要后续实现组合回测：处理股票不能成交、真实换手、买入与卖出的费用、T+1限制、资金约束、仓位与风险敞口；应按每年真实交易规则执行。
8. 对比至少两项指标：历史事件的概率统计，以及在可执行交易条件下的净超额收益和最大回撤。两者可能完全不同。

## 核心反证标准

- 若原版筛选的信号在可交易价格、考虑成本后没有显著的超额收益，应停止继续调参。
- 若V2的收益改善只出现在训练集/特定年份或极少数股票，不能认为改进有效。
- 若V3突破与非突破的差异不稳定，则无需保留额外分类。
- 若先锋动量过滤不带来增量信息，就应从买入条件中剔除先锋，保留它作为纯图形参考。
